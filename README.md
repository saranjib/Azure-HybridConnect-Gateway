# Azure HybridConnect Gateway

### Secure Laptop-to-Azure Private Network Connectivity using Point-to-Site VPN

Azure HybridConnect Gateway is a hands-on Azure networking project that securely connects an **on-premises Windows laptop** to a **private Azure Virtual Network (VNet)** using **Point-to-Site (P2S) VPN with OpenVPN and certificate-based authentication**.

The project demonstrates how a remote/on-premises client can securely access private Azure resources without exposing virtual machines directly to the public Internet.

## Architecture


# Project Goals

The main goals of this project are:

* Build a secure Azure Virtual Network.
* Connect a Windows laptop to Azure using P2S VPN.
* Use OpenVPN for encrypted connectivity.
* Use certificate-based authentication.
* Deploy a private Azure Linux VM.
* Prevent direct Internet access to the VM.
* Control traffic using Network Security Groups.
* Access Azure resources through private IP addresses.
* Demonstrate hybrid/on-premises-to-cloud connectivity.
* Deploy infrastructure using Terraform.
* Monitor and troubleshoot the environment.
